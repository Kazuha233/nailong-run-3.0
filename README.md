# 奶龙快跑 3.0（Nailong Run 3.0）

> 极具叙事性的横版跑酷游戏：在体验不同场景、跨越不同障碍的同时，感受生命的韧性。

致敬 Chrome 小恐龙的横向跑酷游戏，主角为程序绘制的像素奶龙。单 HTML 实现，本地素材运行，支持 **浏览器 / Windows 桌面（exe）/ 安卓（APK）** 三端，云端账号与排行榜由 Supabase 支撑。

## ✨ 更新简介（v3.0）

- 游戏内容全量更新，随枫 4.0 反作弊系统
- 完善游戏架构，优化双端手感
- 优化粒子效果、生态展现、物体建模、动作模组，具备更高机动性
- **3 种模式、2 个角色**，新增技能、强化、血条等游戏设定
- 新增自定义头像等个性化设计

## 🎮 游戏模式

| 模式 | 说明 | 解锁条件 |
|---|---|---|
| 🌿 **普通** | 一望无际的草地，体会天气变化万千 | 默认开放 |
| 🏔️ **极限** | 雪山赛道，天气更恶劣、障碍更凶险，目标冲出雪山；**分数可上榜** | 默认开放 |
| ♾️ **无尽** | 在令人绝望的灰烬中前行——不是因为前方有终点，而是因为自己有不断向前的勇气；**分数覆盖极限成绩并优先上榜（紫色）** | 通关极限模式 |

## 🎛️ 操作方式

- **电脑端**：跳跃 `W / ↑`；蹲下/滑铲 `S / A / ↓ / ←`；技能 `空格 / →`
- **手机端**（可在「操作设置」切换两种方式）：
  - 🖐️ **上下分区**：上半屏跳、下半屏蹲，双击跳区 = 技能
  - 🔘 **经典按键**：左下蹲、右下跳、技能键 💨，按键可自由拖拽、调节大小与透明度

## 🧙 角色

| 角色 | 说明 |
|---|---|
| 🦖 **奶龙** | 默认主角，圆滚滚，永远的主角 |
| 🧙 **依神** | 神秘角色，通关普通模式后解锁 |

## 💨 技能与强化

- **技能**：消耗能量发动，向前冲刺一段距离；空中发动可悬浮滑翔
- **能量**：随时间恢复，攒够一定量才能释放；上限可通过强化提升
- **快落**：跳跃到最高点后按住蹲下，快速落地抢占先机
- **⚡ 强化系统**：主菜单「⚡ 强化」进入——查看角色属性、消耗**能源结晶**加点，提升能量上限与恢复速度
- **🔷 能源结晶**：三种模式都会刷新，收集用于加点

## 🐟 奶鱼护体

- 奶鱼是保命道具：撞上障碍时消耗一条，抵消一次伤害
- **极限模式没有奶鱼补给**——开局携带数量取决于已解锁成就数：成就越多，开局越稳

## 🌦️ 昼夜与天气

| 天气 | 效果 |
|---|---|
| ☀️ 白天 / 🌙 黑夜 | 昼夜交替，夜晚视野更暗 |
| 🌫️ 雾天 | 能见度骤降，前方障碍若隐若现 |
| 🌧️ 雨天（雷暴）| 倾盆大雨加闪电，干扰视线；可浇灭火焰 |
| ❄️ 雪天 | 地面湿滑，跳跃反应变慢、滞空速度变慢 |
| 🌨️ 暴风雪 | 雪天极端形态，雪更密、起跳更滑 |

## 🧱 障碍物

| 障碍 | 说明 |
|---|---|
| 🪨 石块 | 最常见的障碍，跳跃躲避 |
| 🐊 鳄鱼 | 移动速度快，只在夜晚出没 |
| 🌿 荆棘 | 缠住角色无法跳跃，缠绕越深减速越狠（最多五层）；下蹲一次解除一层 |
| ❄️ 细雪 | 雪地中的雪堆，同样会缠身，下蹲挣脱 |
| 🔥 火堆 | 触碰会着火——持续掉血！下蹲可扑灭；下雨会自动浇灭 |
| 🧱 钢筋 / 断墙 | 撞击碎裂，碎片不再挡路 |

## 🏆 成就与排行

- **成就系统**：完成特定挑战解锁成就（通关模式、特定玩法等），可佩戴图标展示在排行榜
- **排行榜**：极限（黄）/ 无尽（紫）双模式；无尽分数覆盖极限成绩且优先排列，比拼实力
- 反作弊：随枫 4.0 系统——分数-时长偏差校验、提交限流、跨提交连续性校验、登录礼包原子防重复

## 🔐 账号与数据

- 登录后可云端同步：成就、解锁进度、加点、能源结晶、当前角色——**更换设备也不丢**
- 🎁 登录礼包：登录即送 10 能源结晶（每人一次）
- 头像、角色选择等个人偏好本地保存

## 🏗️ 技术架构

```
index.html          游戏本体（单文件，全部逻辑）
assets/             素材（BGM / 音效 / 雪碧图 / 开场视频 / 图标）
dev-tools/          运行必需数据脚本（依神数据 / 荆棘 / 细雪 / 渲染）
manifest.json       PWA 清单（全屏 / 横屏）
sw.js               Service Worker（离线缓存）
supabase/           Edge Function 后端源码（auth / score / equip / achieve / enhance）
edge-functions/     后端源码副本（同步维护）
supabase-schema.sql 数据库 Schema（表 / RPC / 反作弊函数，幂等可重跑）
```

**后端（Supabase）**：users（账号 / 成就 / 强化 / 登录礼包标记）、leaderboard（一人一条，无尽紫 > 极限黄单位制）、score_log（反作弊流水）；Edge Function 全代理 + token 校验 + RPC 白名单。
