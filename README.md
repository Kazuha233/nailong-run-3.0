# 奶龙快跑（Nailong Run）

> ⭐⭐奶龙快跑⭐⭐
> 浏览器中小恐龙的改版
> 具有生动活泼的画风！
> 石块、鳄鱼、直升机，多种障碍物！
> 白天、黑夜、雾天、暴风雨，多种天色场景！
> 还有奶鱼可作为护身符！！
> 带上小奶龙！揭晓最终的彩蛋吧！

致敬 Chrome 小恐龙的横向跑酷游戏，主角为程序绘制的像素奶龙。单 HTML 文件实现（本地素材若干），零外部依赖，可在浏览器 / 桌面 / 手机端运行。

## 玩法

- 自动向前奔跑，速度随距离递增（每 280 分 +1，上限 14.5）
- **空格 / 点击 / 触屏**：跳跃（跳过石块、鳄鱼）
- **按住 ↓ / S / 屏幕蹲键**：蹲下（躲避直升机吊挂物，长按有效）
- 得分 = BGM 进度 × 9999，**通关结算正好 9999 分**（匀速计分）
- 收集**奶鱼**：保命道具，撞击时消耗 1 条可破碎障碍并短暂无敌（初始 0 条，全凭路上捡）

## 障碍

| 类型 | 说明 |
|---|---|
| 大石块 | 两种尺寸，地面障碍 |
| 鳄鱼 | 仅黑夜出现（6% 概率），会主动爬向奶龙（额外速度 3.2），比石头快 |
| 武装直升机 | 侧视像素直升机，吊挂动画 GIF（帧序列播放），**必须蹲下躲避**（跳跃会撞），出场音效 |

## 天气与场景

- 昼夜交替：每 400 距离分切换，颜色平滑渐变（约 1 秒过渡），星星渐显
- 雾天：前一半进度仅夜晚起雾，后一半随时随机（雾色随天气：白天白雾 / 夜晚蓝灰雾）
- 雷暴天：进度过半后事件式触发（持续 15~30 秒，间隔 20~45 秒），雨滴 + 随机闪电（全屏白闪，不覆盖 UI）+ 雷声
- 接近终点（BGM 剩余 6 秒）：停止生成障碍与天气，专心冲刺

## 通关演出

BGM 剩余 5 秒雪峰登场 → 镜头逐渐拉远（zoom 0.8）→ 音乐结束 → 字幕「恭喜你，你成功到达了雪峰!」+ 得分 9999。

## 音效

- BGM：自定义背景音乐（assets/bgm.mp3），播放时长决定游戏长度
- 直升机出场音效（实例池 3 个，支持多架重叠播放）
- 奶鱼护体复活音效
- 程序合成音效：跳跃 / 吃鱼 / 撞击 / 破碎 / 雷声 / 胜利三连音
